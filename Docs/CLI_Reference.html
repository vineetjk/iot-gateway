Register Management

CommandDescription
reg add <slave> <addr> <fc> <type> <scale> <tag>Add a register
reg del <index>Delete register by index
reg listList all registers
reg add parameters:
  slave: 1–247 (Modbus address)
  addr: 0x0000–0xFFFF (register address)
  fc: 3=holding, 4=input
  type: u16, i16, u32, i32, f32
  scale: multiplier (float)
  tag: name string (max 19 chars)

Examples:
  reg add 1 0x0000 3 u16 0.1 voltage
  reg add 1 0x0002 3 u32 1.0 energy_kwh
  reg add 2 0x0010 4 f32 1.0 temperature
